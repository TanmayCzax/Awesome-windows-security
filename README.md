
# Awesome Windows Security

A community-curated list of tools, scripts, and frameworks for securing Windows systems in production, enterprise, and lab environments.

This list focuses on practical, actively maintained resources. No dead GitHub repos. No academic theory without working code.

## Categories

- [Hardening & Compliance](categories/hardening.md)
- [Microsoft Defender Ecosystem](categories/defender.md)
- [Identity & Access (AD/AAD)](categories/identity.md)
- [Logging & Detection](categories/logging.md)
- [Offensive Testing (for Blue Teams)](categories/offensive.md)

## Contribution

You found a tool that belongs here. Open a pull request.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting. The only rule is that every tool must solve one specific Windows security task better than alternatives.

## Why this list exists

General security lists are too broad. Windows-specific lists are either outdated or just repackaged blog posts. This repo is maintained by people who actually run Windows security in the wild.
